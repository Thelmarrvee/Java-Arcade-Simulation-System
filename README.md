# Java Arcade Simulation System

## Overview

A Java-based arcade simulation system developed using object-oriented programming and SQL.

## Features

- Customer management
- Game management
- Pricing and discounts
- Age eligibility checks
- Transactions
- Peak and off-peak pricing
- Database integration
- Graphical user interface

## Technologies Used

- Java
- SQL
- IntelliJ IDEA
- GitHub
- SQLite

## Key Concepts

- Object-Oriented Programming
- Event-Driven Programming
- Database Integration
- UML Design
- Software Development Lifecycle
- Testing

## How to Run

1. Clone the repository.
2. Open the project in IntelliJ IDEA.
3. Configure the required database.
4. Run the main Java class.
